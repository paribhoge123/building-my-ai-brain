Day 005: Feedforward Neural Networks (FNN)

What I Learned:

Today I learned about Feedforward Neural Networks (FNNs), one of the fundamental architectures in Deep Learning.

A Feedforward Neural Network is created by connecting multiple neurons together in different layers. Unlike a single perceptron, an FNN can learn more complex patterns and solve problems that cannot be handled by a single neuron.

The term feedforward means that information flows only in one direction—from the input layer to the output layer.

Why Feedforward Neural Networks Were Introduced:

A perceptron can perform simple binary classification tasks, but it has limitations. One of its biggest limitations is that it can only solve linearly separable problems.

To overcome this limitation, multiple perceptrons were connected together, forming a neural network capable of learning more complex relationships from data.

This idea became the foundation of modern Deep Learning.

Structure of a Feedforward Neural Network

A Feedforward Neural Network consists of three main types of layers:

Input Layer

The input layer receives data from the outside world.

Examples of inputs:

Hours Studied
Attendance
Assignment Scores

The input layer does not perform calculations; it simply passes data to the next layer.

Hidden Layer

The hidden layer is where learning takes place.

Each neuron:

Receives inputs
Applies weights
Adds bias
Uses an activation function
Passes the result forward

A neural network can have one or many hidden layers.

Output Layer

The output layer produces the final prediction.

Examples:

Pass or Fail
Spam or Not Spam
Cat or Dog
How Information Flows

In a Feedforward Neural Network, information moves in a single direction:

Input Layer
      ↓
Hidden Layer(s)
      ↓
Output Layer

There are no loops or cycles.

The network processes information step by step until it reaches the final output.

What Makes a Network "Deep"?

A network with multiple hidden layers is called a Deep Neural Network.

The word deep refers to the depth of the network, which is determined by the number of hidden layers.

As more layers are added, the network becomes capable of learning increasingly complex patterns.

Why Feedforward Neural Networks Matter

Feedforward Neural Networks introduced the idea of connecting multiple neurons together to solve complex problems.

They form the foundation of many advanced Deep Learning models and helped pave the way for technologies such as:

Image Recognition
Speech Recognition
Recommendation Systems
Natural Language Processing

Key Takeaways:
A Feedforward Neural Network is made up of multiple interconnected neurons.
Information flows only from input to output.
It consists of input, hidden, and output layers.
Hidden layers perform the actual learning.
Multiple hidden layers lead to Deep Learning.
Feedforward Neural Networks can solve more complex problems than a single perceptron.

Why This Matters:
Understanding Feedforward Neural Networks is important because they represent the transition from a single learning neuron to complete neural networks. Most modern AI systems are built upon the concepts introduced by neural networks, making this a crucial step toward understanding Deep Learning and Large Language Models.
