# Day 066 — Probability Calibration

## 📌 Overview

Classification models can output probabilities, but those probabilities are not always perfectly meaningful.

For example, if a model predicts:

```text
Probability = 0.80
```

we might want approximately 80% of similar predictions to actually be positive.

When predicted probabilities correspond well with observed outcomes, the model is said to be **well calibrated**.

---

## 1. Prediction vs Probability

A classifier can provide:

```text
Class prediction:
0 or 1
```

or:

```text
Probability:
0.0 to 1.0
```

For example:

```text
Transaction A → 0.51
Transaction B → 0.92
```

Both could be classified as class `1` with a threshold of `0.5`, but the model is more confident about Transaction B.

---

## 2. What Is Probability Calibration?

Suppose a model makes 1,000 predictions with approximately:

```text
Probability = 0.8
```

If around 800 of those examples are actually positive, the model is well calibrated around `0.8`.

In general:

```text
Predicted probability ≈ Observed positive frequency
```

---

## 3. Example of Good Calibration

```text
Predicted Probability    Actual Positive Rate

0.1                      0.10
0.2                      0.21
0.3                      0.29
0.4                      0.41
0.5                      0.49
0.6                      0.62
0.7                      0.69
0.8                      0.81
0.9                      0.91
```

The predicted probabilities are close to the actual observed rates.

---

## 4. Example of Poor Calibration

```text
Predicted Probability    Actual Positive Rate

0.1                      0.02
0.2                      0.05
0.3                      0.12
0.4                      0.20
0.5                      0.31
0.6                      0.42
0.7                      0.55
0.8                      0.69
0.9                      0.82
```

The model is overconfident because the observed positive rates are consistently lower than its predictions.

---

## 5. Why Calibration Matters

Probability estimates can be used in:

* Medical risk estimation
* Fraud detection
* Insurance
* Credit risk
* Recommendation systems
* Risk management

If the probability itself is used for decision-making, calibration can be important.

---

## 6. Classification Performance vs Calibration

A model can classify examples correctly while still producing poorly calibrated probabilities.

Therefore:

```text
Good classification
≠
Good probability calibration
```

Calibration focuses specifically on the quality of probability estimates.

---

## 7. Calibration Curve

A calibration curve compares:

```text
Predicted probability
vs.
Observed positive frequency
```

An ideal model approximately follows:

```text
Observed frequency = Predicted probability
```

The closer the calibration curve is to the ideal relationship, the better calibrated the model generally is.

---

## 8. Calibration in Scikit-Learn

```python
from sklearn.calibration import calibration_curve

prob_true, prob_pred = calibration_curve(
    y_test,
    y_proba,
    n_bins=10
)
```

Where:

```text
prob_pred → average predicted probability
prob_true → observed positive fraction
```

---

## 9. Brier Score

The Brier score measures the squared difference between predicted probabilities and actual binary outcomes.

Conceptually:

```text
Brier Score =
Average((predicted probability - actual outcome)²)
```

Example:

```text
Prediction = 0.8
Actual = 1

Error = (0.8 - 1)²
      = 0.04
```

A lower Brier score generally indicates better probabilistic predictions.

---

## 10. Platt Scaling

Platt Scaling uses a logistic/sigmoid transformation to calibrate model scores.

Workflow:

```text
Original Model
      ↓
Model Scores
      ↓
Sigmoid Calibration
      ↓
Calibrated Probabilities
```

It is useful when the calibration relationship can be represented reasonably well by a sigmoid-shaped function.

---

## 11. Isotonic Regression

Isotonic regression learns a non-decreasing mapping from the model's original scores to calibrated probabilities.

Workflow:

```text
Original Scores
      ↓
Learn Monotonic Mapping
      ↓
Calibrated Probabilities
```

It is more flexible than sigmoid calibration but can require more data to avoid overfitting.

---

## 12. CalibratedClassifierCV

Scikit-learn provides:

```python
from sklearn.calibration import CalibratedClassifierCV

calibrated_model = CalibratedClassifierCV(
    model,
    method="sigmoid",
    cv=5
)

calibrated_model.fit(X_train, y_train)
```

For isotonic regression:

```python
calibrated_model = CalibratedClassifierCV(
    model,
    method="isotonic",
    cv=5
)
```

---

## 13. Why Cross-Validation Helps

Calibration should not simply be learned from predictions produced on the exact data used to fit the original model.

Cross-validation helps produce more reliable out-of-sample predictions for learning the calibration mapping.

## 14. Calibration vs Threshold Tuning

These are different concepts.

### Threshold Tuning

Question:

> At what score should the model predict class `1`?

```text
threshold = 0.3
```

### Probability Calibration

Question:

> Does a score of `0.7` actually represent approximately a 70% probability?

Therefore:

```text
Calibration
→ improves probability estimates

Threshold tuning
→ controls the final classification decision
```

---

## 15. Ranking vs Calibration

Suppose the original scores are:

```text
A → 0.90
B → 0.70
C → 0.40
D → 0.20
```

After calibration:

```text
A → 0.75
B → 0.63
C → 0.35
D → 0.18
```

The scores changed, but the ranking can remain:

```text
A > B > C > D
```

Calibration therefore doesn't necessarily change the model's ranking ability.

---

## 🧠 Key Takeaways

* Classification and probability estimation are different.
* A probability of `0.8` should ideally correspond to an observed positive rate near 80% among comparable predictions.
* A model can have good classification performance but poor calibration.
* Calibration is important when probability estimates themselves are used for decisions.
* Calibration curves help visualize probability quality.
* Brier score evaluates probabilistic prediction quality.
* Platt Scaling uses sigmoid calibration.
* Isotonic Regression provides a more flexible monotonic calibration.
* `CalibratedClassifierCV` is available in scikit-learn.
* Cross-validation helps prevent calibration overfitting.
* Threshold tuning and probability calibration solve different problems.
