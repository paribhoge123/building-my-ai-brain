Day 004: Activation Functions in Neural Networks

What I Learned

Today I learned about Activation Functions, one of the most important concepts in Neural Networks.

An activation function is used to determine the output of a neuron after it calculates the weighted sum of its inputs. It acts like a decision-making component of the neuron.

Without activation functions, neural networks would only be able to learn simple linear relationships and would not be capable of solving complex real-world problems.

Why Activation Functions Are Needed

After a neuron receives inputs, multiplies them by weights, and adds a bias, it produces a value.

The activation function decides what should happen next and what output should be sent to the next layer.

The most important role of an activation function is introducing non-linearity into a neural network. This allows neural networks to learn complex patterns from data.

Without activation functions, modern AI applications such as image recognition, speech recognition, and Large Language Models would not be possible.

Types of Activation Functions
Step Function

The Step Function was used in the Perceptron model.

It produces only two outputs:

0
1

This makes it useful for simple binary classification tasks such as Yes/No or True/False predictions.

However, it is too limited for modern deep learning applications.

Sigmoid Function

The Sigmoid Function converts any input value into a number between 0 and 1.

Because of this, its output can be interpreted as a probability.

It is commonly used in binary classification problems but may suffer from the vanishing gradient problem when training deep neural networks.

Tanh Function

The Tanh Function produces outputs between -1 and 1.

Unlike Sigmoid, it is centered around zero, which often helps neural networks learn more effectively.

However, it can still experience the vanishing gradient problem.

ReLU (Rectified Linear Unit)

ReLU is the most widely used activation function in modern deep learning.

It outputs:

The input value itself if the value is positive.
Zero if the value is negative.

ReLU is simple, computationally efficient, and helps neural networks train faster compared to older activation functions.

Key Takeaways
Activation functions determine the output of a neuron.
They introduce non-linearity into neural networks.
Non-linearity enables neural networks to learn complex patterns.
The Step Function is used in Perceptrons.
Sigmoid outputs values between 0 and 1.
Tanh outputs values between -1 and 1.
ReLU is the most commonly used activation function in modern deep learning.
Why This Matters

Activation functions are one of the fundamental building blocks of neural networks. They allow AI systems to learn patterns that would be impossible to capture using simple linear models. Understanding activation functions is essential before moving on to Feedforward Neural Networks and Deep Learning.
