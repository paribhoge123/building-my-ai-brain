# 🚀 Day 069 — Connecting React & Node.js to a Machine Learning API

## Introduction

In Day 068, I built a Machine Learning Prediction API using FastAPI.

Today, I learned how to integrate that API into a full-stack application using React and Node.js.

The goal was to understand how a trained ML model can communicate with a frontend application and become part of a real-world software product.

## 1. Application Architecture

The architecture used in this project:

React → Node.js/Express → Python FastAPI → ML Model

### Responsibilities

* **React:** Collects user input and displays predictions.
* **Node.js/Express:** Handles application logic, validates requests, and communicates with the ML API.
* **FastAPI:** Receives input and performs model inference.
* **ML Model:** Generates the prediction using previously learned patterns.

## 2. Why Use Node.js Between React and FastAPI?

React can communicate directly with FastAPI.

However, in larger applications, Node.js can act as an intermediary backend.

It can handle:

* Authentication and authorization.
* Database operations.
* Business logic.
* Request validation.
* Communication with multiple services.

This makes the application easier to organize and maintain.

## 4. Node.js Backend

Install the required packages:

```bash
npm init -y
npm install express cors
```

Create `server.js`:

```javascript
const express = require("express");
const cors = require("cors");

const app = express();

app.use(cors({
    origin: "http://localhost:5173"
}));

app.use(express.json());

app.post("/api/predict", async (req, res) => {

    const {
        sepal_length,
        sepal_width,
        petal_length,
        petal_width
    } = req.body;

    const values = [
        sepal_length,
        sepal_width,
        petal_length,
        petal_width
    ];

    if (!values.every(
        value =>
            typeof value === "number" &&
            Number.isFinite(value) &&
            value > 0
    )) {
        return res.status(400).json({
            error: "All measurements must be positive numbers."
        });
    }

    try {

        const mlResponse = await fetch(
            "http://127.0.0.1:8000/predict",
            {
                method: "POST",
                headers: {
                    "Content-Type": "application/json"
                },
                body: JSON.stringify({
                    sepal_length,
                    sepal_width,
                    petal_length,
                    petal_width
                })
            }
        );

        const result = await mlResponse.json();

        if (!mlResponse.ok) {
            return res.status(mlResponse.status).json({
                error: result.detail || "ML service error"
            });
        }

        res.json(result);

    } catch (error) {

        res.status(503).json({
            error: "ML service unavailable"
        });

    }

});

app.listen(5000, () => {
    console.log("Node API running on port 5000");
});
```

### How It Works

Node.js receives the frontend request and forwards the input to the Python FastAPI endpoint.

FastAPI uses the trained model to generate a prediction and returns the result to Node.js.

Node.js then sends the response back to React.

## 5. React Frontend

The React application collects four measurements and sends them to the Node.js backend.

Example:

```jsx
import { useState } from "react";

function App() {

    const [formData, setFormData] = useState({
        sepal_length: "",
        sepal_width: "",
        petal_length: "",
        petal_width: ""
    });

    const [prediction, setPrediction] = useState("");
    const [error, setError] = useState("");

    const handleChange = (e) => {
        setFormData({
            ...formData,
            [e.target.name]: e.target.value
        });
    };

    const handlePredict = async (e) => {
        e.preventDefault();

        setPrediction("");
        setError("");

        try {

            const response = await fetch(
                "http://localhost:5000/api/predict",
                {
                    method: "POST",
                    headers: {
                        "Content-Type": "application/json"
                    },
                    body: JSON.stringify({
                        sepal_length: Number(formData.sepal_length),
                        sepal_width: Number(formData.sepal_width),
                        petal_length: Number(formData.petal_length),
                        petal_width: Number(formData.petal_width)
                    })
                }
            );

            const result = await response.json();

            if (!response.ok) {
                throw new Error(result.error || "Prediction failed");
            }

            setPrediction(result.prediction);

        } catch (err) {
            setError(err.message);
        }
    };

    return (
        <div>
            <h1>Iris Flower Prediction</h1>

            <form onSubmit={handlePredict}>

                {Object.keys(formData).map((field) => (
                    <input
                        key={field}
                        type="number"
                        step="any"
                        name={field}
                        placeholder={field.replaceAll("_", " ")}
                        value={formData[field]}
                        onChange={handleChange}
                        required
                    />
                ))}

                <button type="submit">
                    Predict
                </button>

            </form>

            {prediction && <h2>Prediction: {prediction}</h2>}

            {error && <p>{error}</p>}

        </div>
    );
}

export default App;
```


```bash

```

`http://localhost:5173`

Enter the flower measurements and click Predict.

The result comes from the trained ML model through the API integration.

## 7. Common Errors

| Error                     | Possible Cause                                    |
| ------------------------- | ------------------------------------------------- |
| ECONNREFUSED              | ML API is not running                             |
| CORS error                | Browser request is blocked by origin restrictions |
| 422 Unprocessable Entity  | Input format does not match FastAPI's schema      |
| 503 Service Unavailable   | Node.js cannot reach the ML service               |
| 500 Internal Server Error | Error inside the ML service                       |

## 8. Production Considerations

A real application should include:

* Environment variables for service URLs.
* Backend-side input validation.
* Authentication and authorization where required.
* Proper error handling.
* Request timeouts.
* HTTPS communication.
* Secure model file handling.

The example demonstrates the integration process, but additional work is needed before production deployment.
