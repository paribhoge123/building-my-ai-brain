# Day 047: Hyperparameter Tuning

## What I Learned

Today I learned about **Hyperparameter Tuning**, the process of finding the best configuration for a Machine Learning model.

Machine Learning algorithms contain certain settings that must be chosen before training. These settings are called **hyperparameters**. Selecting appropriate values can significantly improve model performance and generalization.

Two common approaches for hyperparameter tuning are **Grid Search** and **Random Search**.

---

## What is a Hyperparameter?

A hyperparameter is a configuration value that is set before the model is trained.

Examples include:

* Number of neighbors in KNN.
* Maximum depth of a Decision Tree.
* Number of trees in Random Forest.
* Learning rate in Neural Networks.
* Regularization strength.

Hyperparameters are different from model parameters because parameters are learned automatically from the training data.

---

## Parameters vs Hyperparameters

### Parameters

Learned during training.

Examples:

* Weights
* Biases

### Hyperparameters

Selected before training.

Examples:

* Learning rate
* Number of neighbors
* Maximum tree depth
* Number of trees
* Regularization strength

---

## Why is Hyperparameter Tuning Important?

Different hyperparameter values can produce significantly different model performance.

For example, in KNN:

```text
K = 1  → Lower performance
K = 5  → Better performance
K = 10 → Lower performance
```

Therefore, finding suitable hyperparameters is an important part of building an effective Machine Learning model.

---

## Grid Search

**Grid Search** evaluates every possible combination of hyperparameters from a predefined set of values.

For example:

```text
max_depth = [3, 5, 7]
min_samples_split = [2, 5]
```

Grid Search evaluates all combinations:

```text
(3,2)
(3,5)
(5,2)
(5,5)
(7,2)
(7,5)
```

The combination producing the best validation performance is selected.

### Advantage

* Systematic and exhaustive.

### Limitation

* Can become computationally expensive when the search space is large.

---

## Random Search

**Random Search** randomly selects combinations from the specified hyperparameter ranges.

Instead of testing every possible combination, it evaluates a fixed number of randomly selected configurations.

For example:

```text
100 possible combinations
        ↓
Randomly select 20
        ↓
Evaluate them
        ↓
Choose the best
```

### Advantage

* More efficient for large search spaces.

### Limitation

* Some potentially good combinations may never be tested.

---

## Grid Search vs Random Search

| Grid Search                       | Random Search                        |
| --------------------------------- | ------------------------------------ |
| Tests every specified combination | Tests randomly selected combinations |
| Systematic                        | More efficient for large spaces      |
| Can be computationally expensive  | Usually requires fewer evaluations   |
| Useful for smaller search spaces  | Useful for larger search spaces      |

---

## Hyperparameter Tuning with Cross Validation

Cross Validation can be combined with hyperparameter tuning to obtain more reliable performance estimates.

For each hyperparameter combination:

1. Divide the training data into multiple folds.
2. Train and validate the model across the folds.
3. Calculate the average validation score.
4. Compare the scores of different configurations.
5. Select the configuration with the best performance.

This approach is commonly implemented using **Grid Search with Cross Validation** or **Random Search with Cross Validation**.

---

## Important: Keep the Test Set Separate

The test set should not be repeatedly used during hyperparameter tuning.

A typical workflow is:

```text
Dataset
   ↓
Training Data
   ↓
Cross Validation + Hyperparameter Tuning
   ↓
Best Hyperparameters
   ↓
Train Final Model
   ↓
Evaluate on Test Data
```

The test set should ideally remain untouched until the final evaluation.

This ensures that the final performance estimate represents how the model performs on genuinely unseen data.

---

## Advantages of Hyperparameter Tuning

* Improves model performance.
* Helps find suitable model configurations.
* Reduces the chance of choosing poor hyperparameters.
* Works with Cross Validation to provide more reliable model selection.

---

## Limitations

* Can be computationally expensive.
* Large search spaces require more resources.
* The best hyperparameters for one dataset may not work equally well for another.

---

## Real-World Applications

Hyperparameter tuning is used in:

* Classification
* Regression
* KNN
* Decision Trees
* Random Forest
* SVM
* Neural Networks
* Deep Learning

---

## How This Fits Into the Bigger Picture

Hyperparameter tuning connects several concepts learned so far.

Cross Validation helps evaluate different configurations reliably, while Regularization controls model complexity and evaluation metrics help determine which configuration performs best.

Together, these techniques form an important part of the Machine Learning model development workflow.

---

## Key Takeaways

* Hyperparameters are settings chosen before training.
* Grid Search tests every specified combination.
* Random Search tests randomly selected combinations.
* Cross Validation can be used during hyperparameter tuning.
* The test set should remain untouched until final evaluation.
* Good hyperparameter selection can significantly improve model performance.

---

## Why This Matters

Hyperparameter tuning is essential for building high-performing Machine Learning models. Even a strong algorithm can perform poorly with unsuitable hyperparameters, while appropriate tuning can significantly improve its generalization and effectiveness.
