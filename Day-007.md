Day 007: Gradient Descent

What I Learned:

Today I learned about Gradient Descent, one of the most important algorithms in Machine Learning and Deep Learning.
After a neural network makes a prediction and calculates the loss, it needs a way to reduce that error and improve its performance. Gradient Descent is the algorithm that helps the model do exactly that.

In simple terms:
Gradient Descent is an optimization algorithm used to minimize the loss of a neural network by updating its weights and biases.

Why Gradient Descent Is Needed:

A neural network starts with random weights and biases, so its initial predictions are often inaccurate.
After calculating the loss, the model needs to determine how to adjust its parameters to make better predictions in the future.
Gradient Descent helps the model move toward values that produce lower loss and better performance.

Mountain Analogy:

A useful way to understand Gradient Descent is by imagining a person standing on a mountain at night.
The goal is to reach the lowest point of the valley.

Since the entire mountain cannot be seen, the person takes small steps downhill, continuously moving toward lower ground.
Similarly, Gradient Descent takes small steps to reduce the loss until the model reaches a point where the error is as low as possible.

In this analogy:

The mountain height represents the loss.
The position on the mountain represents the model's weights and biases.
The valley represents the minimum loss.
Walking downhill represents Gradient Descent.
How Gradient Descent Works

The learning process follows these steps:

Input Data
     ↓
Forward Propagation
     ↓
Prediction
     ↓
Loss Function
     ↓
Loss Value
     ↓
Gradient Descent
     ↓
Updated Weights

The model repeatedly updates its weights and biases to reduce the loss and improve future predictions.

Learning Rate

One of the most important concepts in Gradient Descent is the Learning Rate.

The learning rate controls how large each update step should be.

If the learning rate is too small:

Learning becomes very slow.
Training may take a long time.

If the learning rate is too large:

The model may overshoot the optimal solution.
Training may become unstable.

A good learning rate helps the model learn efficiently while maintaining stability.

Types of Gradient Descent
Batch Gradient Descent

Uses the entire dataset before updating weights.

It is stable but can be slow for large datasets.

Stochastic Gradient Descent (SGD)

Updates weights using one training example at a time.

It is faster but can be noisy.

Mini-Batch Gradient Descent

Updates weights using small batches of data.

It combines the advantages of Batch Gradient Descent and SGD and is commonly used in modern deep learning.

Why Gradient Descent Matters

Gradient Descent is the mechanism that allows neural networks to learn from their mistakes.

Without it, a model could make predictions but would have no way to improve over time.

Almost every modern machine learning and deep learning model relies on some form of Gradient Descent during training.

Key Takeaways
Gradient Descent is used to minimize the loss of a neural network.
It updates weights and biases to improve predictions.
The goal is to move toward lower loss values.
Learning Rate controls the size of each update step.
Batch, Stochastic, and Mini-Batch are common variants of Gradient Descent.
Gradient Descent is one of the core algorithms behind modern AI systems.
Why This Matters

Understanding Gradient Descent is essential because it explains how neural networks actually learn. So far, I have learned how a network makes predictions and measures its mistakes. Gradient Descent is the first concept that shows how the network uses those mistakes to improve itself.
