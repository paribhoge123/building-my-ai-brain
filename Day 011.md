Day 011: RNN Basics (Recurrent Neural Networks)

What I Learned:

Today I learned about Recurrent Neural Networks (RNNs), a type of neural network designed to process sequential data.
Unlike traditional neural networks, RNNs can remember information from previous inputs while processing new inputs. This makes them useful for tasks where the order of data matters.

Examples of sequential data include:

Sentences and text
Speech signals
Stock prices
Weather data
Time-series data

RNNs were developed to handle these types of problems by introducing the concept of memory into neural networks.

Why RNNs Were Introduced:

Traditional neural networks process inputs independently and do not remember previous information.

For example, in a sentence:

I love artificial intelligence understanding the word "intelligence" requires knowledge of the previous words.
A standard neural network cannot naturally maintain this context.
RNNs solve this problem by carrying information from one step to the next through an internal memory mechanism.

The Core Idea: Memory

The most important feature of an RNN is its ability to remember previous inputs.
As data moves through the network, information from earlier steps is stored and used to process future inputs.
This allows the model to understand relationships within sequences rather than treating each input as completely independent.
Because of this memory capability, RNNs are particularly useful for language and time-based applications.

Hidden State

RNNs use something called a Hidden State to store information from previous steps.
The hidden state acts like a short-term memory that is continuously updated as new inputs arrive.

At each step:

Current Input + Previous Hidden State = Updated Hidden State

This updated hidden state is then passed forward to help process the next input in the sequence.

How RNNs Process Data

Instead of processing all inputs at once, RNNs process data one element at a time.
For example, when reading a sentence, the network analyzes each word sequentially while carrying information from previous words.
This allows the model to build context and understand relationships across the sequence.
The memory generated at one step influences predictions made at future steps.

How RNNs Learn

RNNs are trained using the same core concepts used in other neural networks.

Input Sequence
      ↓
Forward Propagation
      ↓
Prediction
      ↓
Loss Function
      ↓
Backpropagation
      ↓
Gradient Descent
      ↓
Updated Parameters

The difference is that the network processes data sequentially while continuously updating its hidden state.

Applications of RNNs

RNNs have been widely used in tasks involving sequential information, including:

Language Modeling
Text Generation
Machine Translation
Speech Recognition
Chatbots
Time-Series Forecasting

These applications benefit from the ability to remember previous information while processing new data.

Limitations of RNNs

Although RNNs introduced memory into neural networks, they struggle with very long sequences.
As sequences become longer, important information from earlier inputs may gradually disappear.
This issue is known as the Vanishing Gradient Problem
As a result, standard RNNs often perform well on short sequences but struggle to capture long-range dependencies.

Improved Versions of RNNs

To overcome the limitations of traditional RNNs, researchers developed more advanced architectures:

LSTM (Long Short-Term Memory)

LSTMs use specialized memory cells that allow them to retain important information for longer periods.

GRU (Gated Recurrent Unit)

GRUs are a simplified version of LSTMs that achieve similar results with fewer parameters.

Both architectures significantly improved sequence modeling and became widely used in Natural Language Processing before the rise of Transformers.

How This Fits Into the Bigger Picture

Previously, I learned about CNNs, which are designed for image-related tasks.

RNNs represent another specialized neural network architecture, but instead of focusing on images, they focus on sequential data and memory.

They introduced the idea that neural networks could maintain context across multiple inputs, which became a major step toward modern language models.

Key Takeaways
RNNs are designed for sequential data.
They maintain memory using a hidden state.
Previous inputs influence future predictions.
RNNs are useful for text, speech, and time-series applications.
Traditional RNNs suffer from the vanishing gradient problem.
LSTM and GRU were developed to address these limitations.
Why This Matters

RNNs played a crucial role in the evolution of Natural Language Processing by introducing memory into neural networks. Although modern AI systems primarily use Transformers, understanding RNNs helps explain how language models evolved and why more advanced architectures were eventually needed.
