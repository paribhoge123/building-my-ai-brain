Day 006: Forward Propagation & Loss Functions

What I Learned:

Today I learned how a neural network makes predictions and evaluates its performance using Forward Propagation and Loss Functions.
These two concepts are at the core of how neural networks learn from data.

Forward Propagation:

Forward Propagation is the process of passing input data through a neural network to generate a prediction.
The data flows through different layers of the network:

Input Layer
     ↓
Hidden Layer(s)
     ↓
Output Layer

At each neuron:

Inputs are multiplied by weights.
A bias is added.
An activation function is applied.
The output is passed to the next layer.

This process continues until the network produces a final prediction.

For example, if a neural network is predicting whether a student will pass an exam, the inputs might be study hours and attendance. After processing these values through multiple layers, the network outputs its prediction.

Forward Propagation is essentially the prediction phase of a neural network.

Loss Functions:

After a prediction is made, the network needs to know how accurate that prediction was.

This is the role of a Loss Function.

A Loss Function measures the difference between the model's prediction and the actual answer.

In simple terms:

A loss function tells the neural network how wrong its prediction is.

A small loss means the prediction is close to the correct answer, while a large loss means the prediction is far from the actual value.

The main goal during training is to reduce this loss as much as possible.

Common Types of Loss Functions
Mean Squared Error (MSE)

Used for regression problems such as:

House Price Prediction
Salary Prediction
Temperature Forecasting

MSE calculates the average squared difference between actual and predicted values.

It penalizes larger errors more heavily.

Binary Cross-Entropy

Used for binary classification problems such as:

Spam or Not Spam
Pass or Fail
Yes or No

It measures how well the predicted probability matches the actual outcome.

Categorical Cross-Entropy

Used for multi-class classification problems such as:

Cat, Dog, or Bird Classification
Handwritten Digit Recognition
Object Recognition

It evaluates how confidently the model predicts the correct class.

How Forward Propagation and Loss Functions Work Together

The learning process of a neural network can be summarized as:

Input Data
     ↓
Forward Propagation
     ↓
Prediction
     ↓
Loss Function
     ↓
Error Measurement

Forward Propagation generates predictions, while the Loss Function evaluates how good or bad those predictions are.

Without a Loss Function, the network would have no way of knowing whether it is improving.

Key Takeaways
Forward Propagation is the process of generating predictions.
Data moves from the input layer to the output layer.
Loss Functions measure prediction errors.
Smaller loss indicates better performance.
Different problems require different loss functions.
The objective of training is to minimize loss.
Why This Matters

Forward Propagation and Loss Functions form the foundation of neural network learning. Forward Propagation helps the network make predictions, while Loss Functions provide feedback on those predictions. Together, they prepare the network for the next step: learning how to reduce errors and improve performance.
