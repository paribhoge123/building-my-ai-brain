Day 008: Backpropagation

What I Learned:

Today I learned about Backpropagation, one of the most important algorithms in Deep Learning.
After a neural network makes a prediction and calculates the loss, it needs to understand which weights and biases contributed to the error. Backpropagation helps the network identify these contributions and calculate how the parameters should be adjusted.

In simple terms:

Backpropagation is the process of sending the error backward through the network to calculate gradients for all weights and biases.
These gradients are then used by Gradient Descent to update the network and improve future predictions.

Why Backpropagation Is Needed:

A neural network may contain thousands or even millions of weights.
When the prediction is wrong, the network knows that an error exists, but it does not automatically know which weights caused that error.
Backpropagation solves this problem by tracing the error backward through the network and determining how much each weight contributed to the final loss.
This allows the model to learn efficiently instead of making random updates.

How Backpropagation Works:

The learning process of a neural network can be summarized as:

Input Data
     ↓
Forward Propagation
     ↓
Prediction
     ↓
Loss Function
     ↓
Loss
     ↓
Backpropagation
     ↓
Gradients
     ↓
Gradient Descent
     ↓
Updated Weights

After the loss is calculated, Backpropagation starts from the output layer and moves backward through the network.
For each weight, it calculates how sensitive the loss is to changes in that weight.

This sensitivity is called a gradient.

The gradients are then passed to Gradient Descent, which updates the weights in a direction that reduces the loss.

Understanding Gradients:

A gradient tells us how much the loss changes when a particular weight changes.
A large gradient indicates that the weight has a significant impact on the error.

A small gradient indicates that the weight has less influence on the error.

By calculating gradients for all parameters, the network knows exactly how to improve itself.

Relationship Between Backpropagation and Gradient Descent

These two concepts work together but have different responsibilities.

Backpropagation calculates the gradients.

Gradient Descent uses those gradients to update the weights and biases.

A simple way to think about it is:

Backpropagation finds what caused the mistake.
Gradient Descent fixes the mistake.

Without Backpropagation, Gradient Descent would not know how to update the network effectively.

The Bigger Picture

At this point, I can see how a neural network learns:

Input
 ↓
Forward Propagation
 ↓
Prediction
 ↓
Loss Function
 ↓
Error Measurement
 ↓
Backpropagation
 ↓
Gradient Calculation
 ↓
Gradient Descent
 ↓
Weight Updates
 ↓
Better Predictions

This cycle is repeated many times during training until the model becomes better at its task.

Key Takeaways:
Backpropagation helps a neural network learn from its mistakes.
It moves backward through the network after the loss is calculated.
It calculates gradients for all weights and biases.
Gradients measure how much each parameter contributes to the error.
Gradient Descent uses these gradients to update the model.
Backpropagation is one of the core algorithms behind modern Deep Learning.
Why This Matters

Before learning Backpropagation, I understood how a neural network makes predictions and measures its errors. Backpropagation completed the picture by explaining how the network identifies the cause of those errors and improves itself over time.

Without Backpropagation, neural networks would not be able to learn efficiently, making modern AI systems such as image recognition models and Large Language Models impossible.
