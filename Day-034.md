# Day 034: K-Nearest Neighbors (KNN)

## What I Learned

Today I learned about **K-Nearest Neighbors (KNN)**, one of the simplest supervised Machine Learning algorithms.

Unlike algorithms such as Linear Regression and Logistic Regression, KNN does not learn a mathematical equation during training. Instead, it makes predictions by comparing a new data point with the most similar examples in the training dataset.

The core idea behind KNN is that **similar data points tend to have similar outputs**.

---

## What is K-Nearest Neighbors?

K-Nearest Neighbors (KNN) is a supervised learning algorithm used for both **classification** and **regression**.

To make a prediction, the algorithm identifies the **K closest data points** in the training dataset and uses their information to determine the output for the new sample.

For classification, it uses majority voting.

For regression, it calculates the average of the nearest neighbors.

---

## How KNN Works

The prediction process consists of four main steps:

1. Calculate the distance between the new data point and every training example.
2. Identify the K nearest neighbors.
3. Analyze the outputs of these neighbors.
4. Predict the final result based on majority voting or averaging.

Unlike many Machine Learning algorithms, KNN performs most of its computation during prediction rather than training.

---

## Distance Measurement

KNN determines similarity using a distance metric.

The most commonly used distance metric is **Euclidean Distance**, which measures the straight-line distance between two points.

Smaller distances indicate greater similarity between data points.

---

## Choosing the Value of K

The value of **K** determines how many neighboring data points influence the prediction.

* A very small K may make the model sensitive to noise and outliers.
* A very large K may ignore important local patterns.

Selecting an appropriate value of K is important for achieving good performance.

---

## Classification Using KNN

In classification problems, KNN predicts the class that appears most frequently among the nearest neighbors.

Examples include:

* Spam email detection
* Disease diagnosis
* Customer classification
* Handwritten digit recognition

---

## Regression Using KNN

KNN can also predict continuous numerical values.

Instead of majority voting, it calculates the average value of the nearest neighbors.

An example is predicting house prices using similar nearby properties.

---

## Lazy Learning Algorithm

KNN is known as a **lazy learning algorithm** because it does not build a model during training.

Instead, it stores the training data and performs calculations only when a prediction is required.

This makes training very fast but prediction comparatively slower, especially for large datasets.

---

## Advantages

* Simple and intuitive.
* Easy to implement.
* Supports both classification and regression.
* No complex training process.
* Works well for small datasets.

---

## Limitations

* Prediction can be slow for large datasets.
* Sensitive to irrelevant features.
* Performance depends on the choice of K.
* Feature scaling is usually required because distance calculations are affected by different units.

---

## Real-World Applications

KNN is commonly used in:

* Recommendation systems
* Image recognition
* Medical diagnosis
* Pattern recognition
* Customer segmentation
* Handwriting recognition

---

## How This Fits Into the Bigger Picture

KNN introduces a completely different learning approach compared to Linear Regression and Logistic Regression.

Instead of learning equations or probabilities, KNN makes predictions based on similarity between data points.

This demonstrates that Machine Learning algorithms can solve problems using different strategies while achieving the same objective of making accurate predictions.

---

## Key Takeaways

* KNN is a supervised learning algorithm.
* It predicts outcomes based on the K nearest neighbors.
* Similar data points are expected to have similar outputs.
* Euclidean Distance is commonly used to measure similarity.
* KNN supports both classification and regression.
* It is known as a lazy learning algorithm because predictions are made using stored training data.

---

## Why This Matters

KNN is one of the easiest Machine Learning algorithms to understand and provides valuable insight into similarity-based learning. It also introduces the importance of distance metrics, feature scaling, and neighborhood-based decision making.
