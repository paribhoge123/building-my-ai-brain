# Day 040: Hierarchical Clustering

## What I Learned

Today I learned about **Hierarchical Clustering**, an unsupervised Machine Learning algorithm that groups similar data points into a hierarchy of clusters.

Unlike K-Means, which requires the number of clusters to be specified in advance, Hierarchical Clustering builds a tree-like structure called a **dendrogram**, allowing the number of clusters to be chosen after analyzing the data.

This makes it particularly useful for exploratory data analysis and understanding relationships between groups of data.

---

## What is Hierarchical Clustering?

Hierarchical Clustering is an unsupervised learning algorithm that organizes data into a hierarchy of nested clusters.

The algorithm progressively merges or splits clusters based on their similarity, creating a tree structure that represents the relationships among the data points.

---

## Types of Hierarchical Clustering

There are two main approaches:

### Agglomerative Clustering

Agglomerative clustering follows a bottom-up strategy.

Each data point starts as its own cluster, and the algorithm repeatedly merges the closest clusters until all data points belong to a single cluster.

This is the most commonly used hierarchical clustering method.

---

### Divisive Clustering

Divisive clustering follows a top-down strategy.

The algorithm begins with one large cluster containing all data points and repeatedly divides it into smaller clusters until the desired structure is obtained.

---

## Dendrogram

A dendrogram is a tree-like diagram that visually represents how clusters are merged or divided during hierarchical clustering.

By selecting a cutting point on the dendrogram, different numbers of clusters can be obtained without retraining the model.

---

## Linkage Methods

To determine which clusters should be merged, the algorithm uses linkage methods that measure the distance between clusters.

Common linkage methods include:

* Single Linkage
* Complete Linkage
* Average Linkage
* Ward's Method

The choice of linkage method influences the final clustering result.

---

## Advantages

* Does not require specifying the number of clusters beforehand.
* Produces an interpretable hierarchy of clusters.
* Easy to visualize using a dendrogram.
* Useful for exploratory data analysis.

---

## Limitations

* Computationally expensive for large datasets.
* Sensitive to noise and outliers.
* Early merging or splitting decisions cannot be reversed.

---

## Real-World Applications

Hierarchical Clustering is widely used in:

* Customer segmentation
* Gene expression analysis
* Document clustering
* Image segmentation
* Biological classification
* Social network analysis

---

## K-Means vs Hierarchical Clustering

Although both are clustering algorithms, they differ in their approach.

* K-Means partitions data into a predefined number of clusters using centroids.
* Hierarchical Clustering builds a hierarchy of clusters without requiring the number of clusters beforehand.
* K-Means is generally faster for large datasets, while Hierarchical Clustering is often preferred for smaller datasets and visualization.

---

## How This Fits Into the Bigger Picture

Hierarchical Clustering expands the understanding of unsupervised learning by introducing hierarchical relationships between data groups.

Together with K-Means, it demonstrates that clustering can be performed using different strategies depending on the dataset and the problem being solved.

---

## Key Takeaways

* Hierarchical Clustering is an unsupervised learning algorithm.
* It organizes data into a hierarchy of clusters.
* Agglomerative clustering merges clusters from the bottom up.
* Divisive clustering splits clusters from the top down.
* A dendrogram visualizes the clustering hierarchy.
* Linkage methods determine how cluster similarity is measured.

---

## Why This Matters

Hierarchical Clustering is an important unsupervised learning technique because it reveals relationships between data points without requiring labeled data or a predefined number of clusters. It provides valuable insights for exploratory analysis and forms the basis for many advanced clustering techniques.
