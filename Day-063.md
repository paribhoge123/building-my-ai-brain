# Day 063 — Model Interpretability: Feature Importance, Permutation Importance & SHAP

## 📌 Overview

Machine Learning models can make accurate predictions, but sometimes we also need to understand **why** they made those predictions.

This is the purpose of **Model Interpretability**.

Instead of only asking:

> "What did the model predict?"

we can ask:

> "Why did the model make this prediction?"

Important interpretability techniques include:

* Feature Importance
* Permutation Importance
* SHAP

---

# 1. What is Model Interpretability?

Model interpretability is the ability to understand how a machine learning model produces its predictions.

Example:

```text
Prediction → High Risk

Important factors:
Credit Score → Strong influence
Debt         → Strong influence
Income       → Moderate influence
Age          → Lower influence
```

Interpretability helps us understand model behavior rather than treating the model as a complete black box.

---

# 2. Why is Interpretability Important?

Interpretability can help with:

* Debugging models
* Detecting data problems
* Understanding important features
* Building trust
* Explaining predictions
* Identifying unexpected model behavior

It can be particularly important in areas such as:

* Healthcare
* Banking
* Insurance
* Fraud detection
* Credit scoring
* Hiring systems

---

# 3. Global vs Local Interpretability

## Global Interpretability

Answers:

> How does the model behave overall?

Example:

```text
Credit Score → 45%
Income       → 30%
Debt         → 15%
Age          → 10%
```

This gives an overall picture of feature influence.

---

## Local Interpretability

Answers:

> Why did the model make this particular prediction?

Example:

```text
Prediction → High Risk

Credit Score → Strong negative contribution
Debt         → Negative contribution
Income       → Positive contribution
```

Therefore:

```text
Global → Understand the model overall

Local → Understand one prediction
```

---

# 4. Feature Importance

Feature importance measures how important different features are according to a model's importance mechanism.

For example:

```text
Feature          Importance

Credit Score       0.42
Income             0.27
Debt               0.18
Age                0.08
Employment         0.05
```

A higher score indicates greater importance according to that particular method.

However:

> Feature importance does not imply causation.

A feature being important to the model does not mean that it causes the target outcome.

---

# 5. Built-in Feature Importance

Many tree-based models provide:

```python
model.feature_importances_
```

Example:

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(random_state=42)

model.fit(X_train, y_train)

importance = model.feature_importances_

for feature, score in zip(X_train.columns, importance):
    print(feature, score)
```

---

# 6. Limitations of Built-in Feature Importance

Built-in tree-based importance can sometimes be misleading.

For example, impurity-based importance can be affected by:

* Features with many possible split points
* Correlated features
* The specific structure of the tree ensemble

Therefore, other interpretability techniques can be useful.

---

# 7. Permutation Importance

Permutation Importance measures how much model performance changes when a feature is randomly shuffled.

Suppose:

```text
Original accuracy = 94%
```

Now shuffle one feature:

```text
Credit Score
↓
Randomly shuffle values
↓
Evaluate model again
```

Suppose:

```text
Accuracy after shuffling = 82%
```

The large performance drop suggests that the model relied heavily on that feature.

---

# 8. Permutation Importance in Scikit-Learn

```python
from sklearn.inspection import permutation_importance

result = permutation_importance(
    model,
    X_test,
    y_test,
    n_repeats=10,
    random_state=42
)

for feature, importance in zip(
    X_test.columns,
    result.importances_mean
):
    print(feature, importance)
```

The larger the performance decrease caused by shuffling a feature, the more useful that feature was to the model under this evaluation.

---

# 9. SHAP

SHAP stands for:

> **SHapley Additive exPlanations**

SHAP is a popular approach for explaining model predictions.

Its main idea is to assign each feature a contribution toward the model's output.

Conceptually:

```text
Base Prediction
      +
Feature A Contribution
      +
Feature B Contribution
      +
Feature C Contribution
      =
Final Prediction
```

---

# 10. Simple SHAP Example

Suppose:

```text
Base prediction = 50%
```

Feature contributions are approximately:

```text
Income        → +15%
Credit Score  → +20%
Debt          → -10%
Age           → +5%
```

Conceptually:

```text
50 + 15 + 20 - 10 + 5
= 80%
```

Actual SHAP calculations are more sophisticated, but the intuition is that each feature receives a contribution toward the final prediction.

---

# 11. Local SHAP Explanation

Suppose a model predicts:

```text
80% probability of approval
```

A SHAP explanation might conceptually show:

```text
Credit Score → +++
Income       → ++
Debt         → -
Age          → +
```

This helps explain **one specific prediction**.

---

# 12. Global SHAP Explanation

SHAP values can also be examined across many observations.

This can help answer:

> Which features generally influence the model's predictions?

Therefore, SHAP can provide both:

```text
Local explanations
        +
Global explanations
```

---

# 13. Comparing Interpretability Methods

| Method                 | Main Question                                                |
| ---------------------- | ------------------------------------------------------------ |
| Feature Importance     | Which features are important according to the model?         |
| Permutation Importance | How much does performance change when a feature is shuffled? |
| SHAP                   | How much did each feature contribute to a prediction?        |

---

# 14. Important: Correlation vs Causation

Interpretability methods describe model behavior.

They do not automatically establish causal relationships.

For example:

```text
Feature A → High importance
```

does not necessarily mean:

```text
Feature A → Causes the outcome
```

It only tells us that the feature has a meaningful relationship with the model's predictions according to the chosen interpretability method.

---

# 🧠 Key Takeaways

1. Model interpretability helps us understand ML model behavior.
2. Global interpretability describes overall model behavior.
3. Local interpretability explains individual predictions.
4. Feature importance identifies important features according to a model's importance mechanism.
5. Permutation importance measures the performance impact of shuffling a feature.
6. SHAP assigns feature-level contributions to predictions.
7. Different interpretability methods have different assumptions and limitations.
8. Model explanations should not automatically be interpreted as causal explanations.
