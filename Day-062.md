# Day 062 — Ensemble Learning: Bagging vs Boosting

## 📌 Overview

Ensemble Learning is a machine learning technique where multiple models are combined to produce a stronger overall model.

Instead of relying on one model:

```text
Data
 ↓
Multiple Models
 ↓
Combine Predictions
 ↓
Final Prediction
```

Two major ensemble strategies are:

1. **Bagging**
2. **Boosting**

---

# 1. What is Ensemble Learning?

Ensemble Learning combines predictions from multiple models.

The individual models are often called **base learners**.

The basic idea is:

> A combination of multiple models can produce better and more stable predictions than a single model.

---

# 2. Bagging

Bagging stands for:

> **Bootstrap Aggregating**

Bagging trains multiple models independently using different bootstrap samples of the training data.

```text
                 Dataset
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
     Sample 1    Sample 2    Sample 3
        ↓           ↓           ↓
     Model 1     Model 2     Model 3
        └───────────┼───────────┘
                    ↓
             Combine Results
                    ↓
             Final Prediction
```

---

# 3. Bootstrap Sampling

Bootstrap sampling means randomly selecting training examples **with replacement**.

Example:

```text
Original:
A B C D E

Bootstrap Sample:
A C C E B
```

Here, `C` appears twice.

Some original examples may not appear in a particular bootstrap sample.

---

# 4. Bagging for Classification

Suppose multiple models produce:

```text
Model 1 → Cat
Model 2 → Dog
Model 3 → Cat
Model 4 → Cat
Model 5 → Dog
```

Majority voting gives:

```text
Cat → 3 votes
Dog → 2 votes
```

Final prediction:

```text
Cat
```

---

# 5. Bagging for Regression

For regression, predictions can be averaged.

Example:

```text
Model 1 → 100
Model 2 → 105
Model 3 → 98
Model 4 → 102
```

Final prediction:

```text
(100 + 105 + 98 + 102) / 4
= 101.25
```

---

# 6. Random Forest

Random Forest is a popular bagging-based ensemble algorithm.

It builds many Decision Trees and combines their predictions.

Random Forest also introduces randomness in the features considered by individual trees.

This helps reduce correlation between trees.

```text
Tree 1 ─┐
Tree 2 ─┤
Tree 3 ─┼→ Combine → Final Prediction
Tree 4 ─┤
Tree 5 ─┘
```

A major advantage of Random Forest is that it can reduce model variance and provide more stable predictions.

---

# 7. Boosting

Boosting is another ensemble strategy.

Unlike Bagging, Boosting builds models **sequentially**.

Each new model attempts to improve the errors made by previous models.

```text
Model 1
   ↓
Find Errors
   ↓
Model 2
   ↓
Improve Previous Errors
   ↓
Model 3
   ↓
Improve Again
   ↓
Final Ensemble
```

---

# 8. AdaBoost

AdaBoost gives more importance to examples that previous models classified incorrectly.

Simplified workflow:

```text
Train Model 1
     ↓
Find Misclassified Samples
     ↓
Give Them More Importance
     ↓
Train Model 2
     ↓
Repeat
```

Several weak learners are combined into a stronger ensemble.

---

# 9. Gradient Boosting

Gradient Boosting builds models sequentially.

Each new model attempts to reduce the errors made by the current ensemble.

Simplified workflow:

```text
Initial Prediction
       ↓
Calculate Error
       ↓
Train Model to Correct Error
       ↓
Update Prediction
       ↓
Calculate New Error
       ↓
Train Another Model
       ↓
Repeat
```

Important algorithms based on boosting include:

* Gradient Boosting
* XGBoost
* LightGBM
* CatBoost

---

# 10. Bagging vs Boosting

| Feature               | Bagging                | Boosting                              |
| --------------------- | ---------------------- | ------------------------------------- |
| Training              | Mostly independent     | Sequential                            |
| Main goal             | Reduce variance        | Correct previous errors               |
| Training relationship | Models are independent | Later models depend on earlier models |
| Parallelization       | Easier                 | More difficult                        |
| Common example        | Random Forest          | XGBoost                               |
| Main strength         | Stability              | Strong predictive performance         |

---

# 11. Real-Life Analogy

### Bagging

Ask 10 people to independently solve a problem and take the majority answer.

```text
Person 1 → A
Person 2 → B
Person 3 → A
...
```

This resembles Bagging.

### Boosting

Ask one person to solve the problem.

Then ask another person to focus on the mistakes of the first.

Then another person focuses on the remaining mistakes.

This resembles Boosting.

# 13. When to Use Bagging

Bagging is useful when:

* The base model has high variance.
* You want more stable predictions.
* You want to reduce overfitting.
* You want models that can be trained independently.
* You need a strong baseline for tabular data.

Random Forest is often a good starting point.

---

# 14. When to Use Boosting

Boosting is useful when:

* Strong predictive performance is important.
* The dataset is structured/tabular.
* You are willing to tune hyperparameters.
* You want to improve performance iteratively.

Boosting algorithms such as XGBoost, LightGBM, and CatBoost are widely used for tabular machine learning problems.

---

# 🧠 Key Takeaways

1. Ensemble Learning combines multiple models.
2. Bagging trains models mostly independently.
3. Bagging commonly uses bootstrap samples.
4. Random Forest is a major bagging-based algorithm.
5. Bagging mainly helps reduce variance and improve stability.
6. Boosting trains models sequentially.
7. Each boosting model tries to improve previous errors.
8. AdaBoost, Gradient Boosting, XGBoost, LightGBM, and CatBoost are boosting methods.
9. Bagging focuses on combining independent learners.
10. Boosting focuses on building a strong learner through sequential improvement.
