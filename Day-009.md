Day 009: Overfitting and Underfitting

What I Learned:

Today I learned about two common problems that occur when training Machine Learning and Deep Learning models: Underfitting and Overfitting.
The goal of a machine learning model is not just to perform well on the training data, but also to make accurate predictions on new, unseen data. Underfitting and Overfitting are two situations where the model fails to achieve this balance.

Underfitting:

Underfitting occurs when a model is too simple to learn the underlying patterns in the data.
In this situation, the model fails to understand the relationships present in the training data, resulting in poor performance on both training and testing datasets.

A model that is underfitting has not learned enough from the data.

Characteristics of Underfitting:

Poor performance on training data.
Poor performance on testing data.
High prediction errors.
Model is too simple or insufficiently trained.
Common Causes
Training for too few epochs.
Using a model with low complexity.
Insufficient features.
Excessive regularization.
How to Reduce Underfitting
Train the model for more epochs.
Increase model complexity.
Add more relevant features.
Reduce excessive regularization.

Overfitting:

Overfitting occurs when a model learns the training data too well, including noise and unnecessary details.
Instead of learning general patterns, the model begins to memorize the training examples. As a result, it performs extremely well on training data but struggles when presented with new data.

A model that is overfitting has learned too much from the training data.

Characteristics of Overfitting:

Very high training accuracy.
Poor testing or validation performance.
Low training loss but high testing loss.
Poor generalization to unseen data.
Common Causes
Excessively complex models.
Insufficient training data.
Training for too many epochs.
Learning noise instead of meaningful patterns.
How to Reduce Overfitting
Collect more training data.
Use data augmentation techniques.
Apply regularization methods.
Use dropout layers.
Implement early stopping.

The Ideal Scenario:

The ideal machine learning model finds a balance between underfitting and overfitting.

Instead of memorizing data or failing to learn patterns, it learns meaningful relationships that can be applied to unseen examples.
This ability is known as generalization, which is one of the most important goals in Machine Learning.

Real-World Analogy:

A useful way to understand these concepts is through exam preparation.

If a student studies very little, they will perform poorly in both practice tests and the final exam. This is similar to underfitting.

If a student memorizes every practice question without understanding the concepts, they may perform well in practice tests but struggle when new questions appear in the exam. This is similar to overfitting.

The best approach is to understand the concepts deeply and apply them to new situations. This represents a well-trained model that generalizes effectively.

How This Fits Into the Bigger Picture

So far, I have learned how neural networks:

Make predictions using Forward Propagation.
Measure errors using Loss Functions.
Calculate gradients using Backpropagation.
Update weights using Gradient Descent.

However, even after successful training, a model can still fail if it does not generalize well to unseen data.

Understanding Underfitting and Overfitting helps explain why model performance must be evaluated beyond the training dataset.

Key Takeaways
Underfitting occurs when the model has not learned enough.
Overfitting occurs when the model learns too much and memorizes data.
The goal is to achieve good generalization.
Training accuracy alone is not enough to judge model performance.
Techniques such as regularization, dropout, and early stopping help reduce overfitting.
Why This Matters

Building a model that performs well on training data is not the ultimate goal of Machine Learning. The true objective is to create models that can make accurate predictions on new, unseen data. Understanding Underfitting and Overfitting is essential for developing reliable and effective AI systems.
