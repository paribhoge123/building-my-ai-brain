# Day 054: CatBoost & Categorical Features

## What I Learned

Today I learned about **CatBoost**, a Gradient Boosting framework developed by Yandex.

CatBoost is particularly designed to work effectively with **categorical features**, making it very useful for structured/tabular datasets containing many categorical columns.

---

## What is CatBoost?

CatBoost stands for **Categorical Boosting**.

Like XGBoost and LightGBM, it builds an ensemble of Decision Trees sequentially.

However, one of its major strengths is its ability to handle categorical features effectively with specialized techniques.

Examples of categorical features include:

* City
* Country
* Gender
* Occupation
* Product Type
* Payment Method
* Subscription Plan

---

## Why Are Categorical Features Challenging?

Most Machine Learning models require numerical input.

Suppose we have:

```text
City

Pune
Mumbai
Delhi
Pune
Delhi
```

These values need to be transformed into a representation that a model can use.

A common approach is **One-Hot Encoding**.

For example:

```text
City_Pune
City_Mumbai
City_Delhi
```

However, if a dataset contains thousands of unique categories, one-hot encoding can create a very large number of features.

CatBoost provides specialized handling for categorical features.

---

## Target Encoding

A common way of representing categorical variables is to use information about the target.

For example, if a particular city has a high proportion of positive outcomes, that information can be represented numerically.

However, directly calculating target statistics using the entire training dataset can cause **target leakage**.

---

## Target Leakage

Target leakage occurs when information that would not be available at prediction time is accidentally used while training the model.

For example, if the target value of an observation is directly involved in calculating the feature representation for that same observation, the model can indirectly gain access to the answer.

This can lead to overly optimistic training performance and poor generalization.

---

## Ordered Target Statistics

CatBoost uses **ordered target statistics** to reduce target leakage.

Instead of calculating category statistics using all observations at once, CatBoost uses an ordering of the training examples.

For a particular observation, category statistics can be calculated using information from previous observations in that ordering.

Conceptually:

```text
A → B → C → D → E

C uses information from A and B
D uses information from A, B and C
E uses information from A, B, C and D
```

The exact implementation is more sophisticated, but the main idea is to prevent the model from using future target information improperly.

---

## Ordered Boosting

CatBoost also uses a technique called **Ordered Boosting**.

Its purpose is to reduce a problem known as **prediction shift** and make the training process more consistent with how predictions are made on unseen data.

The core idea is to carefully control what information is available to the model during training.

---

## Important Hyperparameters

### `iterations`

Controls the number of boosting iterations.

### `learning_rate`

Controls how much each tree contributes.

### `depth`

Controls tree depth.

### `l2_leaf_reg`

Controls L2 regularization.

### `loss_function`

Specifies the loss/objective function.

### `cat_features`

Specifies which features are categorical.

---

## CatBoost vs XGBoost vs LightGBM

| CatBoost                                      | XGBoost                                    | LightGBM                                                     |
| --------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------ |
| Strong categorical handling                   | Strong general-purpose boosting            | Highly efficient and scalable                                |
| Ordered statistics                            | Built-in regularization                    | Leaf-wise growth                                             |
| Ordered boosting                              | Highly optimized                           | Histogram-based learning                                     |
| Often requires less categorical preprocessing | Usually requires categorical preprocessing | Supports categorical features with appropriate configuration |
| Excellent for tabular data                    | Excellent for tabular data                 | Excellent for large tabular data                             |

---

## Advantages

* Excellent categorical feature handling.
* Reduces the need for manual categorical preprocessing.
* Strong performance on tabular datasets.
* Handles nonlinear relationships.
* Supports classification and regression.
* Uses techniques designed to reduce target leakage.

---

## Limitations

* Can be computationally expensive depending on configuration.
* Still benefits from hyperparameter tuning.
* More complex than simple ML algorithms.
* May not be necessary when a dataset contains mostly numerical features.

---

## Example Use Case

Consider a customer churn prediction dataset:

```text
Age
Monthly Charges
City
Occupation
Payment Method
Subscription Plan
```

Numerical features:

```text
Age
Monthly Charges
```

Categorical features:

```text
City
Occupation
Payment Method
Subscription Plan
```

CatBoost is particularly suitable for this kind of structured dataset because it can handle categorical features directly when they are properly specified.

---

## The Modern Boosting Family

The boosting progression I have learned is:

```text
Boosting
   ↓
AdaBoost
   ↓
Gradient Boosting
   ↓
 ┌──────────┬──────────┐
 ↓          ↓          ↓
XGBoost   LightGBM   CatBoost
```

Each framework builds on the general Gradient Boosting idea but focuses on different strengths.

---

## Key Takeaways

* CatBoost stands for Categorical Boosting.
* It is a Gradient Boosting framework.
* It is especially effective with categorical features.
* It uses ordered target statistics to reduce target leakage.
* It uses Ordered Boosting to reduce prediction shift.
* Important parameters include `iterations`, `learning_rate`, `depth`, and `l2_leaf_reg`.
* CatBoost is particularly useful for structured/tabular datasets with categorical columns.

---

## Why This Matters

Real-world datasets often contain many categorical features.

Understanding CatBoost helps me recognize that Machine Learning is not only about choosing a powerful algorithm, but also about choosing an algorithm that matches the structure of the data.
