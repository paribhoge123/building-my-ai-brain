Day 002: Biological Neurons, Artificial Neurons & Activation Functions

What I Learned:

1. Biological Neuron

A biological neuron is the fundamental unit of the human brain. It receives signals, processes information, and sends signals to other neurons.

Main components:

Dendrites → Receive signals
Cell Body (Soma) → Processes information
Axon → Transmits signals
Synapse → Connects neurons and transfers information

The human brain contains billions of interconnected neurons that work together to process information and make decisions.

2. Artificial Neuron

An artificial neuron is a mathematical model inspired by a biological neuron and serves as the basic building block of Artificial Neural Networks (ANNs).

Mapping between biological and artificial neurons:

Biological Neuron	Artificial Neuron
Dendrites	Inputs
Synapses	Weights
Cell Body	Summation Unit
Firing Decision	Activation Function
Axon	Output

Working of an artificial neuron:

Receive input values.
Multiply each input by its corresponding weight.
Add the weighted values and bias.
Pass the result through an activation function.
Generate an output.

3. Activation Functions

An activation function determines whether and how strongly a neuron should produce an output.

Without activation functions, neural networks can only learn simple linear relationships. Activation functions introduce non-linearity, enabling neural networks to solve complex problems.

Common Activation Functions

Step Function
Used in the Perceptron model.

If z ≥ 0 → Output = 1
Else → Output = 0

Sigmoid Function
Output range: 0 to 1
Commonly used for binary classification

Tanh Function
Output range: -1 to 1
Zero-centered output

ReLU (Rectified Linear Unit)
Most widely used activation function in deep learning
If z > 0 → z
Else → 0

Key Takeaways

Artificial neurons are inspired by biological neurons.
Inputs, weights, and bias are used to calculate a neuron's output.
Activation functions help neurons make decisions.
Activation functions introduce non-linearity into neural networks.
ReLU, Sigmoid, and Tanh are widely used in modern deep learning.
The Perceptron uses the Step Activation Function.
