Day 003: Perceptron – The First Learning Neural Network

What I Learned

The Perceptron is the simplest neural network model and is considered the foundation of modern neural networks and deep learning. It was introduced by Frank Rosenblatt in 1957.

A perceptron is essentially an artificial neuron that can learn from data by adjusting its weights based on prediction errors.

Structure of a Perceptron

A perceptron consists of:

Inputs (x1,x2,...,xn)
Weights (w1,w2,...,wn)
Bias (b)
Step Activation Function
Output

The perceptron first calculates a weighted sum:

z=∑i=1nwixi+b

Then it applies a Step Activation Function:

If z ≥ 0 → Output = 1
Else → Output = 0

The output is typically used for binary classification problems such as Yes/No, True/False, Pass/Fail, etc.

How a Perceptron Learns

Initially, the weights are assigned random values.

The perceptron:

Makes a prediction.
Compares it with the correct output.
Calculates the error.
Updates the weights.

Weight update rule:

w new=w old+η(Actual−Predicted)x

Where:

η = Learning Rate
Actual = Correct output
Predicted = Model prediction
x = Input value

This process allows the perceptron to learn from mistakes and improve its predictions.

Advantages
Simple and easy to understand.
First model capable of learning from data.
Introduced core concepts still used in modern neural networks.
Works well for linearly separable data.
Limitation

The perceptron can only solve linearly separable problems.

It cannot solve the XOR problem, where classes cannot be separated using a single straight line.

This limitation led to the development of:

Multi-Layer Perceptrons (MLP)
Artificial Neural Networks (ANN)
Deep Learning models
Key Takeaways
A perceptron is the first learning neural network model.
It uses inputs, weights, bias, and a step activation function.
It learns by updating weights based on prediction errors.
It performs binary classification tasks.
It can solve linearly separable problems but fails on XOR.
Modern neural networks evolved from the perceptron concept.
